# 小王 · 个人作品集

基于原生 HTML / CSS / JavaScript 构建的个人作品集单页网站，展示项目作品、个人介绍与联系方式，支持深浅色主题切换与移动端适配。

## 技术栈

- **HTML5**：语义化单页结构
- **CSS3**：CSS 变量（主题定制）、Grid / Flexbox 布局、媒体查询响应式、内联 SVG 图标
- **原生 JavaScript**：无框架、无第三方 UI 组件库

## 功能特性

1. **项目作品展示**：项目列表由 `script.js` 中的 `PROJECTS` 数组动态渲染，新增项目只需添加一条数据（名称、简介、技术栈、时间、类别、封面图）。
2. **深浅色主题切换**：导航行右侧按钮一键切换；通过覆盖 CSS 颜色变量同步改变背景、文字与边框；使用 `localStorage` 记住用户选择，刷新不丢失；默认浅色主题。
3. **导航滚动高亮**：基于 `IntersectionObserver` 实现滚动时自动高亮当前区块对应的导航项。
4. **移动端适配**：≤960px 时切换为上下布局，导航折叠为汉堡菜单，主题按钮保留在顶部右侧。

## 运行方式

无需构建与依赖，任选其一：

```bash
# 方式一：直接用浏览器打开
index.html

# 方式二：本地静态服务（推荐，主题记忆等功能体验一致）
python -m http.server 8123
# 然后访问 http://127.0.0.1:8123/
```

## 目录结构

```
lab04/
├── index.html      # 页面结构
├── style.css       # 样式（含浅色/深色主题变量与响应式规则）
├── script.js       # 脚本（项目数据、渲染、导航、主题切换）
└── assets/images/  # 头像与项目封面图
```

## 新增项目

打开 `script.js`，在 `PROJECTS` 数组最前面复制一个对象，修改 `name`、`desc`、`stack`、`date`、`category`、`image` 字段即可，页面无需其他改动（越靠前显示越靠上）。
